--- cover letter body ---

Adds riscv64 as a supported VM guest architecture: QEMU/TCG software
emulation on x86_64 hosts (no KVM - no riscv64 hardware to accelerate
against). Builds on the qemu-system-riscv64 target added in the
"PATCH qemu" series [link to that thread once sent] and the sysbus-TPM
fix sent standalone [link once sent].

Verified end-to-end on real hardware: a riscv64 guest boots OpenSBI and
EDK2 UEFI firmware to the boot manager, via both a full ISO install and
an in-place package upgrade. FreeBSD 15.1-RELEASE riscv64 boots to a
shell over the same chain (disk install not completed - blocked on
console/TUI limitations unrelated to this series, not a riscv64 defect).

Two known gaps, tracked as separate bugs rather than folded into this
series:
- ide-cd emits bus=ide.N on virt-machine architectures (no IDE bus
  there); pre-existing, affects aarch64 too. bug #<TBD>
- riscv64 EDK2 firmware publishes ACPI but not FDT, so FDT-only guest
  OSes need `-machine acpi=off` as a workaround. bug #<TBD>

Full writeup, every bug found while building/testing this, and the raw
patches: https://github.com/daemonhorn/pve-riscv64-guest-support
